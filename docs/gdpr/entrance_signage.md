# Entrance signage (GDPR Article 13 transparency)

Print A5, laminate, mount near the entrance. Required so any visitor
knows before crossing the threshold that monitoring is in place.

---

## Suggested copy (English)

> **This home uses indoor positioning sensors.**
>
> - Rooms with cameras: kitchen, living room, yoga room, hallway.
> - Rooms with **no cameras**: bedroom, bathroom — only a thermal fall
>   detector is used there.
> - No images are recorded; only floor positions and (for enrolled
>   residents) names are processed inside the house.
> - No data leaves the home network.
>
> Contact: \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_  (data controller)
